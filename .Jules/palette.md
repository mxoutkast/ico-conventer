## 2024-05-15 - Treeview Keyboard Accessibility
**Learning:** Tkinter Treeview widgets do not natively support list management keyboard shortcuts like `<Delete>` or `<BackSpace>` for item removal, nor standard text selection shortcuts like `<Control-a>` for "select all". These must be explicitly bound. Furthermore, macOS bindings (`<Command-a>`) require explicit wrapping in `try...except tk.TclError` to prevent application crashes on Windows/Linux systems where the modifier is unrecognized. The handler functions must also return `"break"` to prevent default Tkinter event propagation from interfering with custom logic. Finally, when adding a keyboard shortcut, it is beneficial to update the related UI button text (e.g., from "Remove Selected" to "Remove Selected (Del)") to provide a visual hint to users.
**Action:** Always explicitly bind standard accessibility shortcuts for list-like widgets in Tkinter, wrap OS-specific modifiers in try-catch blocks, ensure event handlers return "break", and provide visual hints on related UI buttons.
