## 2024-05-24 - explicit bindings for tk treeview and explicit visual hints
**Learning:** Tkinter Treeview widgets require explicit event bindings for basic list behaviors like item deletion (`<Delete>`, `<BackSpace>`) and "select all" (`<Control-a>`, `<Command-a>`). They are not default behaviors. Furthermore, UI elements should provide visual cues for keyboard shortcuts (e.g. `Remove Selected (Del)`) to improve user accessibility and discoverability. Cross-platform support for Mac keys like `<Command-a>` should be wrapped in a `try...except tk.TclError` block to prevent crashes on Windows/Linux environments.
**Action:** When implementing or modifying lists in Tkinter interfaces, verify that standard keyboard interactions (deletion, select-all) are explicitly bound. Provide keyboard shortcut hints in UI button labels or tooltips. Catch `tk.TclError` when binding OS-specific keys.
