## 2024-05-18 - Tkinter Treeview Keyboard Bindings
**Learning:** Tkinter `Treeview` widgets do not have default keyboard bindings for common list operations like item deletion (`<Delete>`, `<BackSpace>`) or selecting all (`<Control-a>`, `<Command-a>`). Furthermore, when creating custom bindings for these events, returning `'break'` is necessary to prevent default event propagation and potential unwanted side-effects.
**Action:** When implementing lists using Tkinter `Treeview`, explicitly bind these expected keyboard shortcuts to the respective list management handlers to provide an accessible and standard user experience, making sure to return `'break'` in the handlers when modifying selections or propagating custom events. Ensure cross-platform bindings like `<Command-a>` are wrapped in `try...except tk.TclError` blocks to prevent crashes on non-macOS systems.
