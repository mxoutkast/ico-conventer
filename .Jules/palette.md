## 2024-05-18 - Tkinter Treeview Keyboard Accessibility
**Learning:** Default Tkinter Treeview widgets lack built-in keyboard shortcuts for essential list operations such as deleting items (<Delete> or <BackSpace>) and selecting all items (<Control-a>/<Command-a>). Without explicit bindings, keyboard-only users cannot perform these actions, significantly hindering accessibility and UX. Also, when binding custom events like `<Control-a>`, it's critical to return `'break'` to prevent default Tkinter event propagation from interfering.
**Action:** Always explicitly bind `<Delete>`, `<BackSpace>`, `<Control-a>`, and `<Command-a>` (wrapped in a `try...except tk.TclError` for non-macOS platforms) for Treeview widgets. Additionally, provide visual hints in the UI (e.g., updating button text to "Remove Selected (Del)") to educate users about the available shortcuts.
