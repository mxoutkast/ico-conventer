## 2026-07-04 - Explicit Keyboard Bindings in Tkinter Treeview
**Learning:** Standard keyboard shortcuts for lists (like `<Delete>` to remove items or `<Control-a>` to select all) are not default behaviors in Tkinter's `ttk.Treeview`. These essential accessibility and usability features must be explicitly implemented, and the handler methods need to return `'break'` to stop default event propagation. Additionally, cross-platform bindings (like macOS `<Command-a>`) must be wrapped in `try...except tk.TclError` to prevent crashes on non-macOS systems.
**Action:** Always verify keyboard accessibility on custom list components in Tkinter applications and explicitly bind standard shortcuts while updating the corresponding UI labels to make them discoverable (e.g., "Remove Selected (Del)").
