## 2024-05-28 - Keyboard Shortcut Hints in UI
**Learning:** Adding explicit keyboard shortcuts (like <Delete> and <Ctrl-a>) to list components makes power users much happier and improves accessibility for keyboard-only users. The UI needs to visually indicate these shortcuts (e.g., changing "Remove Selected" to "Remove Selected (Del)").
**Action:** When working on lists or Treeview widgets, I should always check if keyboard shortcuts are bound and add them if missing, ensuring I also update the UI text to hint at them. Tkinter treeviews don't have default shortcuts for deleting items.
