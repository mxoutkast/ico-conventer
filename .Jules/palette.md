## 2024-03-09 - Keyboard Bindings for Treeview Manipulation
**Learning:** Tkinter Treeview widgets do not have default keyboard bindings for item manipulation, such as deleting items. Users relying on keyboard navigation expect <Delete> and <BackSpace> to remove items from lists, and <Control-a> / <Command-a> to select all items. Furthermore, making the functionality explicitly discoverable by updating the associated button text (e.g., "Remove Selected (Del)") significantly improves accessibility and usability. When implementing macOS-specific bindings like `<Command-a>`, they must be wrapped in `try...except tk.TclError` to prevent cross-platform crashes.
**Action:** When working with Tkinter Treeview components for file or item lists, always explicitly implement common keyboard shortcuts for list manipulation and add visual hints to corresponding buttons.
