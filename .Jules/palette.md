## 2023-11-20 - Tkinter Treeview Keyboard Shortcuts
**Learning:** Tkinter Treeview widgets (`ttk.Treeview`) do not include default keyboard bindings for standard behaviors such as item removal (e.g., `<Delete>`) or selecting all items (e.g., `<Control-a>`). Furthermore, when adding these custom keyboard bindings, users remain unaware of them unless explicit visual hints are provided in the UI (e.g., updating a "Remove Selected" button to "Remove Selected (Del)"). It is also necessary to wrap macOS-specific bindings like `<Command-a>` in a `try...except tk.TclError` block to prevent crashes on Windows/Linux environments.
**Action:** Always explicitly bind standard keyboard interactions (like deletion and "select all") to list/treeview components in Tkinter. Pair these functional enhancements with explicit visual cues in button text or tooltips. Prevent cross-platform crashes by safely catching `TclError` for OS-specific bindings.
