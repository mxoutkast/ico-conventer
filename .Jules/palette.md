## 2024-07-05 - Tkinter Treeview Keyboard Accessibility
**Learning:** Tkinter Treeview widgets natively lack common list keyboard accessibility interactions (like `Delete` or `BackSpace` for removing items, and `Control-a` or `Command-a` for selecting all). Furthermore, cross-platform support for macOS requires explicit exception handling (`try...except tk.TclError`) when binding `<Command-a>`, as it causes crashes on non-macOS systems. It's also critical to explicitly provide visual hints in the UI (e.g., adding "(Del)" to the removal button) since users expect these standard keyboard behaviors but they aren't visually obvious when missing.
**Action:** Always explicitly bind `<Delete>`, `<BackSpace>`, and `Select All` shortcuts to Tkinter list-like widgets, handle cross-platform shortcut exceptions, and explicitly update UI button text to hint at standard destructive shortcuts.
