## 2024-04-10 - Explicit Keyboard Shortcuts in Tkinter Treeview
**Learning:** Tkinter Treeview widgets do not have default keyboard bindings for common item removal actions (like Delete or Backspace). Additionally, when adding custom keyboard shortcuts, cross-platform compatibility must be considered. Specifically, macOS specific bindings (like `<Command-a>`) will raise a `tk.TclError` on non-macOS systems and must be wrapped in a `try...except` block. Furthermore, event handlers for keyboard bindings should return `'break'` to prevent default Tkinter event propagation. Finally, it's a good practice to explicitly document keyboard shortcuts in the UI (e.g., changing "Remove Selected" to "Remove Selected (Del)").
**Action:** When working with Tkinter Treeview, explicitly add bindings for `<Delete>` and `<BackSpace>` if item removal is expected. Wrap macOS specific bindings like `<Command-a>` in `try...except tk.TclError`. Ensure handlers return `'break'` when appropriate, and update UI labels to hint at available keyboard shortcuts.
