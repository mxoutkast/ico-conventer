## 2024-04-29 - Explicit Keyboard Bindings Required for Tkinter Treeviews
**Learning:** By default, Tkinter's `ttk.Treeview` widget does not provide keyboard bindings for item removal (like `<Delete>` or `<BackSpace>`) or selecting all items (`<Control-a>`/`<Command-a>`). Furthermore, when adding cross-platform support like `<Command-a>` for macOS, attempting to bind these on non-macOS systems can raise a `tk.TclError` and crash the application if not handled with a try/except block. Lastly, adding visual hints in the UI (e.g., "Remove Selected (Del)") significantly improves feature discoverability.
**Action:** When implementing list or table UI components using Tkinter in future tasks, explicitly bind common accessibility keyboard shortcuts to expected behaviors and wrap macOS-specific bindings in `try...except tk.TclError` to prevent cross-platform crashes. Add visual hints in text to help users discover shortcuts.
