## 2026-04-24 - Keyboard Shortcut Hint Standards\n**Learning:** When adding keyboard shortcuts like <Delete> to Treeview widgets, users may not know they exist since Tkinter does not provide default visual indicators. Updating button text to explicitly display the shortcut (e.g. 'Remove Selected (Del)') bridges the gap between power-user keyboard support and general accessibility/discoverability.\n**Action:** Whenever adding new hotkeys to standard UI components, always pair the code binding with a visible text hint in the UI.
