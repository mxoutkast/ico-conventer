## 2024-06-16 - Add keyboard shortcuts for file list in Tkinter Treeview
**Learning:** Users naturally expect keyboard shortcuts like `<Delete>` or `<BackSpace>` to remove items and `<Control-a>` to select all in list views. However, Tkinter's `Treeview` widget does not provide these behaviors by default. Adding explicit keyboard shortcuts significantly improves the accessibility and efficiency of the UI without any visible clutter. Modifying the button label slightly (e.g. "Remove Selected (Del)") acts as a useful hint for keyboard accessibility.
**Action:** When implementing custom list widgets or `Treeview` components in Tkinter (or other similar GUI frameworks), explicitly bind standard keyboard shortcuts for selection (`<Control-a>`, `<Command-a>`) and deletion (`<Delete>`, `<BackSpace>`) early in the development process and provide visual hints if appropriate. Ensure handlers return `'break'` to prevent default framework event propagation where necessary.
