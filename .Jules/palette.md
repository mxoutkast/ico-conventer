## 2024-04-02 - Tkinter Treeview Keyboard Accessibility
**Learning:** In Tkinter, default components like `ttk.Treeview` lack basic keyboard accessibility shortcuts that users expect, such as `<Delete>`/`<BackSpace>` to remove items or `<Control-a>`/`<Command-a>` to select all. Additionally, cross-platform key handling (like `<Command-a>` on non-macOS systems) must be wrapped in `try...except tk.TclError` to prevent crashes. Furthermore, keyboard event bindings in Tkinter must explicitly return `'break'` to prevent default event propagation if custom handling is implemented. Also, always add visual hints in the UI text (e.g., 'Remove Selected (Del)') to inform users of these accessibility features.
**Action:** Always implement explicit bindings for common list operations (`<Delete>`, `<Control-a>`) when using `ttk.Treeview`, gracefully handle platform-specific keys using `try/except`, return `'break'` in custom handlers to stop propagation, and provide visual keyboard hints in button labels.
