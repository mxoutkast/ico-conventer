## 2024-03-21 - Tkinter Treeview Implicit Keyboard Event Expectations
**Learning:** Unlike modern UI frameworks, Tkinter `ttk.Treeview` components do not provide default keyboard shortcuts for common list management interactions such as deleting items (`<Delete>` or `<BackSpace>`) or selecting all items (`<Control-a>`/`<Command-a>`). Users expect these standard shortcuts to function in any list view. Also, cross-platform mappings (like `<Command-a>` for macOS) must be implemented defensively by catching `tk.TclError` since they cause crashes on non-macOS systems.
**Action:** When adding list/table views using `ttk.Treeview` in Tkinter applications, explicitly bind standard keyboard interactions for deleting and selecting items to improve accessibility and UX. Also, update button labels in the UI to visually hint at these shortcuts (e.g., "Remove Selected (Del)").
