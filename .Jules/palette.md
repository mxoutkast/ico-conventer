## 2024-05-30 - Keyboard Shortcuts and Hinting for Lists
**Learning:** Tkinter Treeview widgets don't have built-in support for item removal via `<Delete>` or `<BackSpace>` by default, nor do they support `<Control-a>` for selection out of the box. Adding explicit bindings for these actions significantly improves accessibility and power-user experience. Furthermore, hinting at these shortcuts in the UI text (e.g., adding "(Del)" to the Remove button) is crucial for discovery.
**Action:** Always add explicit keyboard bindings (`<Delete>`, `<BackSpace>`, `<Control-a>`, and macOS safe `<Command-a>`) when using list widgets like Tkinter's Treeview. Ensure the handlers return `'break'` to stop default event propagation if necessary. Update associated button labels to visually hint at the shortcuts (e.g., "Remove Selected (Del)").
