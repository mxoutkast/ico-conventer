## 2024-05-24 - Tkinter List Keyboard Bindings & UX Hints
**Learning:** Tkinter Treeview widgets do not natively support keyboard interactions like deleting or selecting all items. Furthermore, wrapping macOS-specific shortcut bindings (like `<Command-a>`) in `try...except tk.TclError` blocks is a critical cross-platform stability requirement to prevent application crashes on non-macOS systems. Finally, updating button labels to include the keyboard shortcut (e.g., "Remove Selected (Del)") creates a more intuitive and discoverable UX for users relying on keyboard navigation.
**Action:** When implementing interactive lists or tables in Tkinter, always explicitly bind expected standard keyboard shortcuts (`<Delete>`, `<BackSpace>`, `<Control-a>`). Always handle potential `TclError` exceptions for OS-specific bindings. Complement explicit bindings with visible hints on corresponding UI controls to improve accessibility and discoverability.
