## 2024-05-27 - Tkinter Treeview Keyboard Bindings
**Learning:** Default standard UI list shortcuts, like using the `<Delete>` and `<BackSpace>` keys to remove items, or `<Control-a>` to select all, are not bound automatically to Tkinter Treeview widgets and must be explicitly bound. Furthermore, it's a good UX practice to indicate the presence of such shortcuts using a visual hint in the UI button text (e.g., changing "Remove Selected" to "Remove Selected (Del)").
**Action:** Next time I work with a Tkinter Treeview or similar component, I will proactively ensure common interaction patterns via keyboard shortcuts are configured, and that their bindings provide visual hints to users who rely on the keyboard, along with `return 'break'` if appropriate to stop default sequence propagation.
