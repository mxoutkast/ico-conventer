## 2024-03-11 - Cross-platform Tkinter Keyboard Accessibility
**Learning:** Adding keyboard shortcuts (like `<Delete>` or `<BackSpace>`) significantly improves list-based GUI usability. However, macOS-specific bindings (e.g., `<Command-a>`) will raise a `tk.TclError` on non-macOS systems, which can crash the application during widget initialization. Furthermore, explicit visual hints on interactive elements (like appending "(Del)" to the "Remove Selected" button text) teach users about hidden accessibility features they might otherwise miss.
**Action:** Always wrap platform-specific Tkinter keyboard bindings in a `try...except tk.TclError:` block to prevent fatal errors on other operating systems. Additionally, always provide visual hints for destructive or primary actions when a keyboard shortcut is introduced.
