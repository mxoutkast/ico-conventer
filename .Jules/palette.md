## 2026-06-10 - Tkinter Treeview Keyboard Accessibility
**Learning:** Tkinter Treeview widgets do not natively support standard list behaviors like deleting items or selecting all. These must be manually bound using specific key events (e.g., `<Delete>`, `<BackSpace>`, `<Control-a>`). Additionally, cross-platform considerations are necessary, as macOS specific bindings like `<Command-a>` require a `try...except tk.TclError` wrapper to prevent crashes on non-macOS systems. Event handlers bound this way should return `'break'` to stop event propagation.
**Action:** When implementing new Tkinter Treeviews or lists, always explicitly bind keyboard shortcuts for common list management actions to ensure proper accessibility and include visual cues in UI labels (e.g., '(Del)'). Wrap macOS-specific bindings in a try/except block.
