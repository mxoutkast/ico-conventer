## 2024-06-15 - Tkinter Treeview Shortcuts
**Learning:** Tkinter Treeview widgets do not have default keyboard shortcuts for basic file list interactions like item removal (<Delete>, <BackSpace>) or 'Select All' (<Control-a>, <Command-a>). These must be explicitly bound. Furthermore, visual hints in the UI (e.g., 'Remove Selected (Del)') are critical to communicate these explicit bindings to the user. Additionally, cross-platform shortcuts like <Command-a> for macOS must be wrapped in a try...except tk.TclError block to avoid crashing the app on other platforms.
**Action:** When implementing new Tkinter Treeview components, always explicitly bind necessary selection and deletion shortcuts, include visual hints for accessibility, and ensure cross-platform compatibility with error handling for OS-specific bindings.
