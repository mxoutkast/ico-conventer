## 2024-05-23 - Keyboard Shortcuts and Visual Hints
**Learning:** Adding keyboard shortcuts (like Delete for removing items) significantly improves usability for power users, but they must be discoverable. Adding a visual hint in the button text (e.g., "Remove Selected (Del)") is a simple, effective way to bridge the gap between mouse and keyboard interaction without cluttering the UI.
**Action:** Always pair invisible keyboard shortcuts with visible UI hints, either in tooltips or directly in the button label.
