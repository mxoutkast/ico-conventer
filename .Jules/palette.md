## 2024-05-16 - [Tkinter Treeview Keyboard Accessibility]
**Learning:** Tkinter Treeview widgets don't have default keyboard shortcuts for basic operations like item removal (Delete/BackSpace) or select all (Ctrl+a/Cmd+a). Explicit bindings are required to support basic keyboard navigation and interaction. Also, event handlers in Tkinter must return `'break'` to prevent default event propagation when implementing custom keyboard bindings. Furthermore, mapping macOS specific keys like `<Command-a>` must be wrapped in a `try...except tk.TclError` block to avoid crashing on non-macOS systems.
**Action:** Always add explicit keyboard bindings (`<Delete>`, `<BackSpace>`, `<Control-a>`) for custom list components, ensure event handlers return `'break'` if they are overriding default behaviors, handle macOS bindings safely, and add text hints to UI buttons (e.g. "Remove Selected (Del)") to improve discoverability of shortcuts.
