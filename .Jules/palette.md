## 2024-05-24 - Tkinter Treeview Accessibility & Keyboard Shortcuts
**Learning:** Tkinter `ttk.Treeview` components do not provide built-in keyboard shortcuts for common list actions like deletion (e.g., `<Delete>` or `<BackSpace>`) or selecting all items (`<Control-a>`, `<Command-a>`), even when `selectmode='extended'` is enabled. Users relying on keyboard navigation are forced to use the mouse to delete items or perform bulk selections unless explicit event bindings are added.
**Action:** Always explicitly bind standard keyboard shortcuts (`<Delete>`, `<BackSpace>`, `<Control-a>`) to custom handler methods when using `ttk.Treeview` for lists, and return `'break'` from selection handlers to prevent unwanted default Tkinter event propagation. Additionally, cross-platform bindings for macOS (`<Command-a>`) should be wrapped in `try...except tk.TclError` to prevent application crashes on non-macOS systems. Always visually hint at critical keyboard shortcuts in the UI text (e.g., "Remove Selected (Del)").
