## 2024-05-24 - Tkinter Treeview Keyboard Bindings
**Learning:** Tkinter Treeview widgets lack default keyboard bindings for standard selection and deletion actions.
**Action:** Always add explicit keyboard bindings (`<Delete>`, `<BackSpace>`, `<Control-a>`, `<Command-a>`) to Treeview widgets for item removal and selection, and include visual hints (e.g., '(Del)') in the UI to improve accessibility and user experience.
