## 2024-05-24 - Tkinter Treeview Keyboard Accessibility
**Learning:** Tkinter `Treeview` widgets require explicit bindings for basic list interactions like removing items (`<Delete>`, `<BackSpace>`) and selecting all items (`<Control-a>`, `<Command-a>`), as these are not provided by default. Additionally, providing explicit visual hints in UI labels (e.g., `"Remove Selected (Del)"`) significantly improves discoverability for these essential keyboard shortcuts, particularly for screen reader and keyboard-only users who might not otherwise know the bindings exist.
**Action:** When implementing list or table components in Tkinter applications, proactively add default keyboard bindings for standard interaction patterns and ensure the UI explicitly references critical shortcuts in relevant buttons or labels.
