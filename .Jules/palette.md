## 2024-05-24 - Tkinter Treeview Keyboard Accessibility and Visual Hints
**Learning:** In Tkinter, `ttk.Treeview` widgets do not automatically inherit expected keyboard shortcuts like `<Delete>` or `<BackSpace>` for item removal, nor `<Control-a>` or `<Command-a>` for 'Select All'. Additionally, providing an explicit visual hint in the UI text (e.g., adding `(Del)` to a button label) is crucial for improving discoverability and accessibility of these shortcuts for non-mouse users. Also, custom keyboard event bindings in Tkinter must return `'break'` to prevent default event propagation.
**Action:** When implementing interactive lists or Treeviews in Tkinter, explicitly bind expected keyboard actions (`<Delete>`, `<Control-a>`, etc.), return `'break'` to stop propagation, and provide clear visual hints in associated UI buttons to ensure a complete and accessible user experience.
