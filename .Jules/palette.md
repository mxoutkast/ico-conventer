## 2024-05-18 - Keyboard Accessibility and Shortcut Hints in Tkinter Treeview
**Learning:** Tkinter Treeview widgets do not come with default bindings for common keyboard actions like item deletion (`<Delete>`, `<BackSpace>`) or selecting all (`<Control-a>`, `<Command-a>`). Additionally, visual hints on UI elements (like adding "(Del)" to a delete button) significantly improve usability and discoverability for these actions.
**Action:** When adding keyboard shortcuts to interact with UI components like lists or trees in Tkinter, always remember to explicitly implement and bind these events, handle platform-specific keys carefully (e.g., `<Command-a>` with `try...except tk.TclError`), and update corresponding buttons or labels with keyboard shortcut hints to guide the user.
