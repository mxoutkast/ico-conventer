## 2024-06-11 - [Tkinter List Accessibility - Keyboard Shortcuts]
**Learning:** Tkinter Treeview widgets in this project require explicit bindings for basic list actions like item removal (`<Delete>`, `<BackSpace>`) and 'Select All' (`<Control-a>`, `<Command-a>`), as these are not default behaviors. Users expect these standard shortcuts to work for desktop applications. Furthermore, cross-platform Tkinter bindings for macOS specific keys (like `<Command-a>`) must be wrapped in `try...except tk.TclError` to prevent crashes on non-macOS systems. Event handlers should return `'break'` to stop propagation. Also the UI needs to indicate standard shortcut keys in the button text to aid discoverability, like 'Remove Selected (Del)'.
**Action:** When implementing a Tkinter Treeview or list component, always add and explicitly bind standard keyboard shortcuts for common actions, handle cross-platform exceptions for key combinations, properly stop event propagation, and surface the shortcuts in the UI text.
