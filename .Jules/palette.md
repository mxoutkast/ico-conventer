
## 2024-05-18 - Keyboard Accessibility in Tkinter Treeview Lists
**Learning:** Tkinter Treeview widgets do not come with default keyboard bindings for item removal (`<Delete>`, `<BackSpace>`) or selection (`<Control-a>`, `<Command-a>`). They require explicit bindings. Also, when providing keyboard shortcuts, it's beneficial for UX to add visual hints to the corresponding UI elements (e.g., adding "(Del)" to the "Remove Selected" button).
**Action:** When working with Tkinter Treeview widgets, proactively add keyboard shortcuts for common operations (deletion, selection) and include visual hints in the UI to improve discoverability and accessibility for keyboard users.
