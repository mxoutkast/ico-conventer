## 2024-07-06 - Tkinter Treeview Keyboard Bindings
**Learning:** Tkinter Treeviews lack default keyboard bindings for standard UX actions like `<Delete>`, `<BackSpace>`, or 'Select All' (`<Control-a>`, `<Command-a>`). Furthermore, when implementing cross-platform bindings, macOS-specific keys (`<Command-a>`) will raise a `tk.TclError` on non-macOS systems and crash the app if not properly handled. Returning `'break'` from event handlers is essential to prevent unintended default event propagation in Tkinter.
**Action:** Always explicitly bind standard accessibility shortcuts (`<Delete>`, `<Control-a>`) to Treeviews. Provide visual hints in the UI (e.g., 'Remove Selected (Del)'). Wrap macOS-specific bindings in a `try...except tk.TclError` block to ensure robust cross-platform support. Ensure all custom event handlers return `'break'` if they consume the event.
