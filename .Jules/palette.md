## 2024-05-24 - ttk.Treeview Keyboard Accessibility
**Learning:** By default, Tkinter's `ttk.Treeview` widget does not provide standard keyboard accessibility features like selecting all items (`<Control-a>`) or deleting items (`<Delete>` or `<BackSpace>`). Additionally, bindings specific to macOS (`<Command-a>`) can crash the application on Windows or Linux if not explicitly wrapped in a `try...except tk.TclError` block.
**Action:** Always explicitly implement keyboard bindings for selection and deletion when using `ttk.Treeview` to ensure full keyboard accessibility. Furthermore, gracefully handle cross-platform shortcut bindings to avoid runtime errors on non-target operating systems. Add visual hints (e.g., "Remove Selected (Del)") to corresponding UI buttons to discoverability.
