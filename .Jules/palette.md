## 2024-05-18 - Explicit Tkinter List Bindings
**Learning:** By default, Tkinter Treeview widgets do not have keyboard bindings for essential operations like item removal (Delete/Backspace) or select all (Ctrl+A). Users might try these common shortcuts and assume the UI is unresponsive or broken if they are missing. Furthermore, macOS users require `Command-a` mappings which should be implemented with fallback protection (`try...except tk.TclError`) to avoid cross-platform crashes.
**Action:** Always explicitly bind `<Delete>`, `<BackSpace>`, `<Control-a>`, and macOS `<Command-a>` for Tkinter list components, ensuring the bound functions return `'break'` to prevent default event propagation. Additionally, update the corresponding button text (e.g. "Remove Selected (Del)") to provide discoverable visual hints for these keyboard shortcuts.
